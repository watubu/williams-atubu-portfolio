# Williams Atubu — Software Engineering Portfolio

React + TypeScript + Vite portfolio.

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Contact form email

The contact form sends submissions to `williamsatubu99@gmail.com` through FormSubmit. On the first submission, confirm the activation email FormSubmit sends to that inbox; submissions can be delivered after the recipient is activated.

## Main files

- `src/App.tsx` — page content and interactions
- `src/index.css` — visual system and responsive styles
- `index.html` — SEO metadata
- `public/robots.txt` — crawler rules
- `public/sitemap.xml` — sitemap
- `favicon.svg` — favicon
- `tests/tests.txt` — QA coverage

## Push to GitHub

```bash
git init
git add .
git commit -m "Initial portfolio"
git branch -M main
git remote add origin https://github.com/watubu/YOUR-REPO-NAME.git
git push -u origin main
```

Replace `YOUR-REPO-NAME` with the repository you create.
